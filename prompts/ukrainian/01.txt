Створи статичну HTML-сторінку (один файл, без CSS/JS фреймворків) — генератор Google site: запитів для пошуку вакансій. Назва сайту: jobgrep.

ФОРМА:
- Поле "Job Title" з <datalist> популярних dev-тайтлів
- Поле "Location" з <datalist> популярних локацій
- Поле "Extra Keywords" (необов'язкове, для довільних слів)
- Чекбокс "Remote only"
- Pill-кнопки фільтру дати: Any time / Past hour / Past 24h / Past week / Past month / Past year (реалізувати через Google параметр &tbs=qdr:X)
- Кнопка "Generate Links" (також спрацьовує на Enter в будь-якому полі та Cmd/Ctrl+Enter глобально)
- Кнопка "Clear" — скидає всі поля форми та результати одним кліком

ЗБЕРЕЖЕННЯ СТАНУ В URL:
- При кожному натисканні "Generate Links" поточний стан форми (title, location, keywords, remote, date filter) автоматично записується в query params (?t=...&l=...&k=...&r=1&d=qdr:w) через history.replaceState — без перезавантаження
- При завантаженні сторінки стан відновлюється з query params і генерація запускається автоматично
- Кнопка "Share Search" просто копіює поточний URL (який вже містить актуальний стан)

ГЕНЕРАЦІЯ:
Для кожного сайту зі списку будується Google-запит:
  site:{domain} AND "{title}" AND "{location}" AND "remote"
де remote і location додаються лише якщо заповнені/вибрані.
URL: https://www.google.com/search?q={encoded_query}&tbs={tbs}

РЕЗУЛЬТАТИ — картки, згруповані по секціях.
Над усіма секціями заголовок з лічильником: "25 links generated".
Кожна картка: іконка-абревіатура | назва сайту + preview запиту | кнопка "copy" (копіює запит) + кнопка "open →" (відкриває Google в новій вкладці) + кнопка "×" (приховати сайт).

СПЕЦІАЛЬНА ГРУПА "⭐ Recommended":
- Показується лише якщо в полі Job Title є одне з: Go, Golang, Rust, Elixir, Clojure, Scala, Erlang (case-insensitive, перевіряти входження)
- Містить один сайт: { name: "ReadyToTouch", domain: "readytotouch.com", code: "RT" }
- Відображається першою, перед ATS Platforms

ПРИХОВУВАННЯ САЙТІВ:
- Клік на "×" опускає картку в самий низ секції в окрему групу "Hidden", де вона відображається блідо зі скороченим виглядом і кнопкою "restore"
- Список прихованих доменів зберігається в localStorage

RECENTLY CLICKED:
- Останні 5 сайтів, на які натиснули "open →", підсвічуються зеленим бордером і бейджем "recent"
- Стан зберігається в localStorage, оновлюється одразу без перерендеру

ТЕМА:
- Перемикач Light/Dark, стартує з prefers-color-scheme системи
- <meta name="theme-color"> оновлюється разом із темою (темний фон для dark, кремовий для light)

СТИЛЬ: мінімалістичний, монохромний з червоним акцентом (#c0392b) і зеленим для recent/restore (#2c7a4b), моноширинний шрифт (Courier New), кремовий фон (#f5f2eb). Без зовнішніх шрифтів і бібліотек. SEO meta-теги включити.
