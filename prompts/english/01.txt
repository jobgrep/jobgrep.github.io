Create a static HTML page (single file, no CSS/JS frameworks) — a Google site: search query generator for job hunters. Site name: jobgrep.

FORM:
- "Job Title" field with <datalist> of popular dev titles
- "Location" field with <datalist> of popular locations
- "Extra Keywords" field (optional, for arbitrary words)
- "Remote only" checkbox
- Date filter pill buttons: Any time / Past hour / Past 24h / Past week / Past month / Past year (implemented via Google parameter &tbs=qdr:X)
- "Generate Links" button (also fires on Enter in any field and Cmd/Ctrl+Enter globally)
- "Clear" button — resets all form fields and results in one click

URL STATE PERSISTENCE:
- On every "Generate Links" click, current form state (title, location, keywords, remote, date filter) is automatically written to query params (?t=...&l=...&k=...&r=1&d=qdr:w) via history.replaceState — no page reload
- On page load, state is restored from query params and generation runs automatically
- "Share Search" button simply copies the current URL (which already contains the current state)

GENERATION:
For each site in the list, a Google query is built:
  site:{domain} AND "{title}" AND "{location}" AND "remote"
where remote and location are included only if filled in / checked.
URL: https://www.google.com/search?q={encoded_query}&tbs={tbs}

RESULTS — cards grouped by sections.
Above all sections, a header with a counter: "25 links generated".
Each card: abbreviation icon | site name + query preview | "copy" button (copies query) + "open →" button (opens Google in new tab) + "×" button (hide site).

SPECIAL GROUP "⭐ Recommended":
- Shown only if the Job Title field contains one of: Go, Golang, Rust, Elixir, Clojure, Scala, Erlang (case-insensitive substring match)
- Contains one site: { name: "ReadyToTouch", domain: "readytotouch.com", code: "RT" }
- Displayed first, before ATS Platforms

HIDING SITES:
- Clicking "×" moves the card to the bottom of the results in a separate "Hidden" group, where it appears faded in a compact view with a "restore" button
- The list of hidden domains is persisted in localStorage

RECENTLY CLICKED:
- The last 5 sites where "open →" was clicked are highlighted with a green border and a "recent" badge
- State is persisted in localStorage and updated immediately without re-rendering

THEME:
- Light/Dark toggle, starts from the system prefers-color-scheme
- <meta name="theme-color"> updates together with the theme (dark background for dark, cream for light)

STYLE: minimalist, monochromatic with red accent (#c0392b) and green for recent/restore (#2c7a4b), monospace font (Courier New), cream background (#f5f2eb). No external fonts or libraries. Include SEO meta tags.
